# Claude 101 — Tổng quan khóa học

**Nguồn:** Anthropic Skilljar — Claude 101 (bản tiếng Việt v2.0) · ~3 giờ đọc + 2-4 giờ thực hành · Cơ bản → Trung cấp

## Ý chính

Claude là **thinking partner**, không chỉ là chatbot: đọc, viết, nghiên cứu cùng bạn và tự động hóa quy trình lặp lại hàng tuần.

## 5 nguyên tắc cốt lõi

1. **Claude mang trí tuệ, bạn mang bối cảnh và chuyên môn** — prompt trống → kết quả trống.
2. **Phản hồi đầu tiên chỉ là điểm khởi đầu** — lặp và tinh chỉnh.
3. **Projects lưu kiến thức, Skills thực hiện quy trình** — dùng cùng nhau.
4. **Giao việc lặp lại, giữ việc cần phán đoán** (chiến lược, tuyển dụng, đạo đức).
5. **Kiểm tra trước khi tin** — AI có thể "ảo giác"; thử trên task bạn đã biết kết quả.

## Công thức prompt

**Bối cảnh + Nhiệm vụ + Quy tắc** (tông giọng, độ dài, định dạng...).

## 3 sai lầm của người mới

| Sai lầm | Cách đúng |
|---|---|
| Prompt 1 dòng ("Viết email cho khách") | Thêm bối cảnh: ai, tình huống, giọng điệu, độ dài |
| Tải 50 file lộn xộn vào Project | Đặt tên file mô tả, chỉ tải file liên quan, tham chiếu theo tên |
| Dùng Claude như Google | Việc lặp ≥ 3 lần → tạo Project/Skill; copy-paste từ Slack/Gmail → dùng Connector |

## Chuẩn bị

- **Bắt buộc:** tài khoản Claude (Projects/Skills/Connectors cần Pro/Max/Team/Enterprise), claude.ai, 2-4 tài liệu thật, danh sách 3-5 việc lặp hàng tuần.
- **Nên có:** Chrome (extension), 1 connector (Drive/Slack/Notion/Gmail), đồng nghiệp để thử tính năng nhóm.

## Kết quả mong đợi

- ≥ 1 Project phục vụ công việc thật
- ≥ 1 Skill tùy chỉnh
- ≥ 1 workflow tích hợp Connector, tiết kiệm > 2 giờ/tuần
- 1 báo cáo Research để chia sẻ với nhóm

## Bài tập khởi động (5 phút)

Ghi ra: 3 việc hàng tuần tốn > 2 giờ · 3 loại tài liệu viết nhiều nhất · 1 dự án lớn cần tham khảo liên tục.
