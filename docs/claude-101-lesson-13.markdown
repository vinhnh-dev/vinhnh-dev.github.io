# Bài 13: Tóm tắt và bước tiếp theo

**Module 5 — Áp dụng thực tế** · ~10 phút · Tổng kết

## Nhìn lại 5 module

| Module | Điểm cốt lõi |
|---|---|
| **1. Làm quen (01-03)** | Claude = thinking partner (hữu ích - vô hại - trung thực; Constitutional AI; steerable; context 200K+, tới 1M với Opus). Prompt **C-T-R**, tải file thay vì dán, lặp lại. **Khung 4D** (Delegation, Description, Discernment, Diligence) + vòng lặp Delegation–Diligence |
| **2. Môi trường (04)** | Desktop có 3 chế độ: **Chat** (Quick Entry, screenshot, dictation), **Cowork** (scheduled tasks, sub-agents, folder access, Dispatch), **Code** (Ask/Code/Plan) |
| **3. Tổ chức (05-07)** | **Projects** (kiến thức dài hạn, RAG tự động, tên file rõ, 3 mức quyền) · **Artifacts** (output độc lập, tái sử dụng, chia sẻ/publish; coi như template) · **Skills** (built-in xlsx/pptx/docx/pdf + custom). Projects = knowledge, Skills = execution |
| **4. Mở rộng (08-10)** | **Connectors + MCP** ("USB-C cho AI", quyền có phạm vi, thu hồi được) · **Enterprise Search** ("Ask [Your Org]") · **Research** (đa bước 5-45 phút, báo cáo có trích dẫn) |
| **5. Ứng dụng (11-12)** | **Use case theo vai trò** + khung chấm điểm (Tần suất ×3 + Thời gian ×2 + Setup + Độ ổn định ×2) · **Flavors**: Code → dev, Slack → teamwork, Excel → bảng tính, Chrome → web |

## 5 nguyên tắc xuyên suốt

1. **Claude mang trí tuệ, bạn mang bối cảnh và chuyên môn.** Prompt mơ hồ = kết quả mơ hồ.
2. **Phản hồi đầu tiên là điểm khởi đầu.** Lặp và tinh chỉnh; biết khi nào nên bắt đầu lại.
3. **Projects lưu kiến thức, Skills thực thi nhiệm vụ.** Bổ trợ nhau, không thay thế.
4. **Giao việc lặp lại, giữ việc cần phán đoán** (chiến lược, đạo đức, trách nhiệm).
5. **Kiểm tra trước khi tin, tin rồi vẫn xác minh.** Vòng lặp giao → kiểm tra → điều chỉnh, đặc biệt với việc rủi ro cao.

## Bước tiếp theo: bắt đầu ngay

Không chờ "học thêm 2 khóa", "team ủng hộ" hay "tính năng mới". Chọn **1 việc lặp lại tuần này** (email khách, tóm tắt họp, phân tích bảng tính, chuẩn bị họp, báo cáo tiến độ) → thử với Claude → lặp lại → rút ra cách hợp với bạn.

**Claude là người cộng tác, không phải người thay thế.** Chuyên môn, bối cảnh, phán đoán, quan điểm, mối quan hệ và giá trị vẫn là của bạn.

## Lộ trình 30-60-90 ngày

| Giai đoạn | Hành động | Mục tiêu |
|---|---|---|
| **Ngày 1-30** Xây thói quen | Hàng ngày: dùng Claude ≥ 1 việc · Hàng tuần: tạo 1 Project cho luồng việc quan trọng nhất + kết nối 1 công cụ mới · Cuối tháng: đánh giá thời gian tiết kiệm, chất lượng, điều chỉnh | Muscle memory, chưa cần tối ưu |
| **Ngày 31-60** Mở rộng & tự động hóa | 2-3 Custom skill cho việc lặp · ≥ 1 Scheduled Task trong Cowork (daily brief / báo cáo tuần) · Chạy Research lần đầu · Bắt đầu dùng flavor hợp vai trò (Code/Excel/Slack/Chrome) | Từ dùng rời rạc → quy trình có hệ thống |
